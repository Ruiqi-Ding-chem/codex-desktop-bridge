# Changelog

## 0.1.0 (unreleased)

First public version.

- Background mode: `run` and `continue` through `codex exec`, with model, reasoning effort, sandbox and project chosen per run.
- Visible mode: `visible` opens a prefilled new thread, or a prefilled follow-up, in the Codex desktop app and waits for the answer.
- `doctor`, `projects`, `models`, `read` and `open`.
- Tested with Codex desktop app 26.1111 (codex-cli 0.169.1) on Windows 11.
